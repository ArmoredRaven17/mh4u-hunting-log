How this works

  • Pick a quest on the left — search by quest name, monster or locale, or browse by board and star.
  • The quest fills in its own locale and objective; everything else is yours to write.
  • Urgent and Key pills are the game's own flags from the quest files. The Caravan opens up through its story, so only some of its quests carry the Key flag. Frenzy and Apex are the OUTBREAK markers the game puts on the quest's icons.
  • Guild Quests are built from relics, so there's one Guild Quest to pick; give its Relic Level (1-140) and its monsters, and the log names it "Guild Quest Lv 85 / Rajang + Kirin". The monster lists hold only what the game can put in a Guild Quest at that level — Lv 1-30 draws on Low Rank, 31-85 High Rank, 86-140 G Rank, and some monsters change with the level (Rajang is Furious Rajang at Lv 76-85). The Elder Dragons and Gore Magala come alone. The row is only open while a Guild Quest is selected.
  • Save Entry adds it to the logbook on the right. Click any entry to edit it again.
  • Timestamp is on by default, so the date is set the moment you save. Turn it off to fill the date in yourself.
  • Farming the same quest? Turn on Farming and the form stays filled after each save, so back-to-back runs only need whatever actually differed.
  • Already saved a run and want another like it? Open it, change what differed, and press Save as New to file it as a second hunt instead of overwriting the first.
  • Tick entries and press Copy Selected to put them on the clipboard — handy for pasting a session into Discord. Shift-click a second tick box to take everything in between; All ticks the whole log.

Saving

  • The log saves itself in this browser as you type — including the entry you're part-way through writing, which is waiting for you when you come back.
  • New starts an empty logbook — save the current one first if you want to keep it.
  • Save writes it out to a .json file and Open loads one back. Keep separate files for separate playthroughs.
  • Clearing your browser's site data wipes the in-browser copy, so keep a file if the log matters.

MH4U Hunting Log

An unofficial, non-commercial logbook for Monster Hunter 4 Ultimate — record what you hunted, what you wore, who came along, and why. Not affiliated with, endorsed by, or supported by Capcom.

Every quest — its name, star, locale, objective, monsters, time limit, fee and reward — is read from the game's own quest files, and the monster, quest and weapon icons are the game's own. Everything was extracted from a personally owned copy of the game; no game files are redistributed. Downloadable Event Quests aren't on the cartridge, and Guild Quests are generated from relics rather than stored, so neither is listed. The quest list was cross-checked against Kiranico; no data is taken from it.

Monster Hunter 4 Ultimate and all of its names, data and icons are © CAPCOM CO., LTD. The UI textures and the MHFU font are shared with the same author's MHGU fan apps, and the app itself is a port of the MHGU Hunting Log.
